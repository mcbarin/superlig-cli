# superlig-cli

Terminal client for Turkish Super Lig (Spor Toto Süper Lig) - Display league standings in your terminal.

## Features

- 📊 Displays league standings with full statistics
- 🎨 Beautiful terminal output using Rich library
- 🌐 Data sourced from soccerstats.com
- ⚡ Fast and lightweight

## Installation

Install directly from GitHub:

```bash
pip install git+https://github.com/mcbarin/superlig-cli.git
```

Or using uv (faster):

```bash
uv pip install git+https://github.com/mcbarin/superlig-cli.git
```

## Usage

```bash
superlig
```

That's it! The command displays the current league standings.

## Requirements

- Python 3.10 or higher
- Internet connection (data is scraped from soccerstats.com)
